About Me

I’m Thom, a self‑taught web developer from New Zealand now based in Paris. I’ve noticed that my friends and I always choose venues where we can preview the website, soak up the vibe and check an up‑to‑date menu before we go. My goal is to modernise small cafés, bars and restaurants by crafting simple sites that reflect each business’s atmosphere and follow the owner’s guidelines.

My demo portfolio includes a minimalist café page with smooth parallax scrolling, a restaurant showcase with an interactive image gallery and embedded reservation form, and a moody bar site featuring English and French versions via a language toggle. Every project is built from scratch with semantic HTML, modern CSS (Flexbox and Grid) and JavaScript for carousels, menus and forms. I host and version everything on GitHub and deploy instantly through GitHub Pages. I’ve also used Python to automate finding local businesses on Google Maps that lack a website, so I can offer them a straightforward, pixel‑perfect online presence.
